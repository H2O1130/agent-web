# 前端开发说明

需求、数据契约与规则见顶层 [`需求与分工.md`](../需求与分工.md)；分支与 PR 流程见其第 6.1 节。文中路径相对 `frontend/`。

## 1. 运行

```sh
cd frontend
npm ci
npm run dev          # http://127.0.0.1:5173/
npm run typecheck
npm test
npm run test:e2e     # 先起 5173，用本机 Chrome
npm run build        # frontend/dist/
```

固定端口：`npm run dev -- --port 5173 --strictPort`。E2E 失败截图在 `test-results/`，六档截图写到 `output/screenshots/`（均已忽略）。

联调后端：复制 `.env.example` 为 `.env.local`，设置 `VITE_API_BASE=http://127.0.0.1:8000`；不设置时用本地规则。

## 2. 页面

| 路由 | 页面 | 职责 |
| --- | --- | --- |
| `/` | Home | 入口、载入演示画像 |
| `/plan` | Wizard | 六步画像 + 样本选择 |
| `/analysis` | Analysis | 能力、证据、课程映射；`?plan` / `?skill` |
| `/roadmap` | Roadmap | 按学期和寒暑假分组、双列微任务卡、详情折叠、总览、完成勾选、导出 |
| `/adjust` | Adjust | 改条件生成新方案与差异 |
| `/history` | History | 版本列表、两份对比、删除 |
| 其他 | NotFound | 404 |

生成链路：`store.generate` → `planning.createPlan` → 新方案进 `store.plans`；其余页面只读方案快照。共享状态放 Pinia，页面内 UI 状态留在页面。

## 4. 改代码注意

1. E2E 锁文案：标题、主要按钮名、导出文件名，改文案同步改用例。
2. `localStorage` 键 `pathpilot-workspace`；增删 `Profile` / `Plan` 字段必须同步 `store.ts` 读取校验。
3. 差异状态与 CSS 类名绑定：`.status-保留/推迟/新增/移除`。
4. 新增页面改两处：`router.ts` 路由 + `App.vue` 的 `nav`。
5. `SkillChart` 在 `onMounted` 建实例、`onBeforeUnmount` 清理；容器必须有高度。
6. 快照不可变：不要直接改 `plan.tasks`；调整页先深拷贝原方案。
7. 已新增 `src/api.ts`；`store.generate` 为 async。配置 `VITE_API_BASE`（见 `.env.example`）时走 `/api/plan`，未配置时用本地 `createPlan`；远程失败直接提示，不静默回退。
8. 页头「模型设置」把自己填的 DeepSeek 密钥存进 `localStorage` 的 `pathpilot-llm`，请求时以 `X-DeepSeek-Key` / `X-DeepSeek-Model` 头发给后端，优先于 `.env`；`/api/llm/verify` 用于「测试连接」。
9. 合并进 `master` 只允许 `git merge --no-ff <分支>`（见 `需求与分工.md` 6.1），不走 PR、不做快进。
10. `Plan.overview`、`Plan.semesters`、`PlannedTask.example`、`weekNote` 为可选字段，旧方案没有也能渲染；Markdown 导出会带上总览、学期分组和示例。

## 5. 验收与演示

- [ ] 四条命令全绿；六档宽度无溢出
- [ ] 键盘可走完向导；手机输入不被遮挡；`prefers-reduced-motion` 无动画
- [ ] 页面无团队/分工/汇报入口
- [ ] 0 小时全部待安排；调整条件后旧方案不变；学期顺序与前置关系正确

演示顺序：载入演示画像 → 选样本生成 → 看证据与映射 → 路线勾选/导出 → 一键 12→6 → 历史对比 → 手机宽度。

## 6. 排错

| 现象 | 处理 |
| --- | --- |
| `/roadmap` 404 | 用 `/#/roadmap`（Hash 路由） |
| 改样式没生效 | 检查文件末媒体查询是否覆盖 |
| 图表空白 | 容器需有高度；实例需已挂载 |
| 提示「本地记录无法读取」 | 数据与校验不符；重置或删 `localStorage['pathpilot-workspace']` |
| 端口被占 | `npm run dev -- --port 5173 --strictPort` |
| E2E 缺浏览器 | 装 Chrome，或移除 `channel: 'chrome'` 后装 Chromium |
