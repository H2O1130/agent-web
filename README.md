# 学途 PathPilot

一个使用 TypeScript、Vue 3 和 Vite 构建的大学生成长规划静态前端。UI 采用浅色背景、金色进度与选中态、橙色主按钮，适配手机、平板和桌面。

页面仅保留首页、画像填写、岗位分析、成长路线、方案调整和历史记录，不展示项目介绍、团队成员、分工或课程汇报信息。

## 启动

推荐使用 Node.js 22.12 或更新的兼容版本。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。当前开发预览使用 `http://127.0.0.1:5173/`。如端口被占用，Vite 会提示另一个端口；需要固定端口可使用 `npm run dev -- --port 5173 --strictPort`。

## 功能

- 六步画像向导，支持草稿自动保存、自评和每周时间填写。
- 两个岗位方向、12 条演示样本，支持选择、查看原文和导入文本。
- 技能归并去重、明确要求与加分项分类、证据与课程/实践映射。
- 8 学期总览，按任务前置关系与每周工时预算安排当前及后续学期。
- 时间、岗位、路径变化后的方案调整；兴趣用于可选实践的安排顺序与解释。
- 新旧方案对比、历史记录、完成标记和 Markdown 导出。
- 历史方案的证据查看使用该方案保存的样本，不改写当前画像草稿。

首页可点击“载入演示画像”体验完整向导，确认岗位后生成路线。历史计划通过顶部导航访问，调整页提供 12→6 小时演示。

## 验证和构建

```sh
npm run typecheck
npm test
npm run test:e2e
npm run build
npm run preview
```

浏览器测试使用本机 Chrome，运行前先启动 `npm run dev -- --port 5173 --strictPort`。测试配置见 `playwright.config.ts`；需要已安装 Chrome。如使用 Playwright 自带 Chromium，可在安装浏览器后移除配置中的 `channel: 'chrome'`。

`npm test` 验证岗位证据、前置关系、预算、条件调整和快照保护。浏览器测试验证桌面/手机主流程、导出、历史证据、岗位导入、键盘跳转、输入遮挡和本地记录恢复，并检查 320、390、768、1024、1440、1920px 下的页面溢出。代表截图保存在 `output/screenshots/`。

构建产物在 `dist/`，可部署到提供静态文件服务的站点。当前 `base: './'`，使用 Hash 路由，支持静态子目录部署；通过 HTTP 服务预览，不直接双击构建后的 HTML。

## 必要依赖

| 依赖 | 当前用途 |
| --- | --- |
| Vue、TypeScript、Vite | 组件、类型与本地开发/构建 |
| Vue Router | 现有页面之间的导航与 Hash 路由 |
| Pinia | 实际跨页面共享的画像、样本与历史方案 |
| Apache ECharts | 岗位技能频次图表，按需加载 |
| @lucide/vue | 本地图标组件，按需引入 |
| vue-tsc、Vitest、Playwright | 类型、核心规则和浏览器验证 |

样式使用原生 CSS，没有额外 UI 框架。没有服务层、后端 API、模型适配器或占位实现。

## 代码位置

- `src/views/`：实际页面。
- `src/components/`：重复使用的选择卡、岗位选择器与需要管理生命周期的图表。
- `src/planning.ts`：需要独立验证的岗位分析、任务排期与差异计算。
- `src/data/jobs.json`：12 条明确标识的演示招聘样本。
- `src/data.ts`、`src/types.ts`：当前使用的技能映射与业务数据类型。
- `src/store.ts`：跨页状态与本地保存。
- `src/style.css`：视觉规范及响应式布局。

## 演示范围

当前没有调用大模型或实时招聘网站；岗位统计来自所选演示样本或用户导入文本。招聘文本按关键词、别名及分句规则分析，复杂表述应人工核对。

课程关联和每学期 16 周均为示例，需按学校培养方案与真实教学日历校准。每周预算指课外成长时间。放不下的任务保留为待安排，不强行排到毕业之后。自评仅代表本人认识，不推导就业概率或薪资。

数据保存在当前浏览器。清理浏览器数据会删除本地记录，可以提前导出计划。若未来实际开展真实 AI 接入，再根据届时确定的需求实施，不提前添加接口。
