# 后端开发说明

只启动「分学期规划」一个模块；其他端点未开工。需求见顶层 [`需求与分工.md`](../需求与分工.md)。

## 结构

```text
backend/
├── 开发说明.md
└── semester-planning/
    ├── README.md             接口、校验、DeepSeek 配置
    ├── requirements.txt
    ├── requirements-dev.txt
    ├── .env.example
    ├── app/                  FastAPI（待实现）
    └── tests/                pytest
```

新模块沿用：模块根放 `README.md` + 依赖文件，代码进 `app/`，测试进 `tests/`。

## 运行

需要 Python 3.12+。

```sh
cd backend/semester-planning
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
uvicorn app.main:app --reload --port 8000
pytest
```

macOS / Linux 用 `source .venv/bin/activate`。

## 约定

- 请求/响应字段 camelCase，与 `frontend/src/types.ts` 一致。
- 错误统一 `{ code, message }`，`message` 为中文。
- 模型只输出任务 id、学期、周次、理由；静态字段后端回填。
- 校验失败或超时重试 1 次，仍失败直接报错，不回退本地引擎。
- 密钥只走环境变量；`.env` 不入库；日志不打印密钥。
